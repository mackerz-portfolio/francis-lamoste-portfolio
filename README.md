# Francis Lamoste — Graphic Design Portfolio

Responsive dark futuristic portfolio for branding, packaging, book covers, and digital design.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then click **Save**.
4. After publishing, your website should be available at: https://mackerz-portfolio.github.io/francis-lamoste-portfolio/

## Before sharing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
- Replace the generic Behance and LinkedIn links with your profile URLs.
- Replace the illustrative preview images with your own projects. They are not presented as verified client work.
- Update project captions and case studies with accurate details.

The site is a single `index.html` file and needs no build tools or paid hosting.
